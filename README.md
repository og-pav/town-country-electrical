# Town & Country Electrical Co. — website

Multi-page static site, generated by `build.py` (Python 3, stdlib only).

## Live
GitHub Pages: https://og-pav.github.io/town-country-electrical/

## Rebuild / change base URL
    python3 build.py <base-url>
Every internal link, canonical, sitemap, robots and schema follows the base URL.
When moving to the real domain (or Vercel), rerun with the new base and push.
